# IMDB-Score-Predictor
Using R as my coding language of choice, I take a dataset of the 1,000 highest rated IMDB movies from the past and use them in an attempt to try to find which variables are statistically significant in order to predict the scores of movies released after the dataset's creation that should now be included
IMDB scores were chosen due to ease of entry with getting the data nad because it is all easy to understand, allowing better foundations for more complicated Data Science and Data Analytics work
